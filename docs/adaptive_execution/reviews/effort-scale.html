Why both readings agree

In these stationary, unclipped trials, reported effort depends on motor gain multiplied by sensor scale. A factor of 0.70 in either produces the same observation. If a healthy joint must keep its exact torque, the controller must abstain at this state. The minimax correction allows some healthy-joint error and chooses the command that minimizes the larger torque error across these two explanations.

Measurement details

Native MuJoCo 3.16.0, Unitree G1 left knee, nominal stiffness 75 N·m/rad. The first 20 ms command is limited to 2 rad/s and 0.20 rad total displacement. The torque sampler is synchronized with the joint state and reads after joint limits. The experiment used zero walking episodes.

What walking must establish

First verify that repeated healthy runs agree. Then test whether joint motion lets an online controller distinguish true gain loss from a sensor error during walking. Compare falls, tracking error and unnecessary correction with the same command limits.
