# AE-014 · Delivered sample age and withdrawal in the pilot report

In WP 2.2 at `4bb9142`, the audit retained actual hip and knee age histograms and each episode recorded its withdrawal step. The report omitted actual packet age, truncated fractional median steps and presented the median without the number of episodes that withdrew. A median based on one observed withdrawal could therefore look representative of an entire method arm. [Issue #49](https://github.com/pchatla-arch/anticipatory-balance/issues/49) · [Review request](https://github.com/pchatla-arch/anticipatory-balance/pull/46#issuecomment-7087672852)

Report mean age in milliseconds separately for hip and knee joint ticks where the transition was observed and a valid source existed. A post-transition capture available at the next decision has age zero. Missing sources have no age. For return-to-healthy cells, report the median steps among withdrawals alongside counts of episodes that withdrew, finite episodes that reached the scheduled return, and all episodes scheduled to return. A finite terminal transition at the return counts as observed. Regression tests include a half-step median, a pre-return termination, an invalid episode, a stale sample and an absent source.
